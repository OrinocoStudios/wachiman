# Security policy

Wachiman is a security tool, so bugs in it matter twice.

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub's *Report a vulnerability* button (Security tab of this repository). You will get an answer within a week.

Especially relevant:

- Anything that makes Wachiman record content (keystrokes, audio, screen, message bodies) instead of metadata.
- Ways to read the local history or the bot token from another user account or a sandboxed app.
- Ways to silence alerts without the owner noticing.
